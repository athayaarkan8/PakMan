# PakMan

!Lakukan Instruksi Berikut jika Menggunakan CMake

## Compile

```bash
cmake --build build
```

## Jalankan

```bash
.build/pakman
```

## Kontrol Game

- `W` `A` `S` `D`: Gerak pemain
- `Z`: Rewind ke posisi sebelumnya (energi terbatas)
- `Q`: Pause / Resume game

## Tujuan

Ambil paket (`$`) lalu antarkan ke titik delivery (`!`) sambil menghindari ghost (`>`).

Have Fun!
